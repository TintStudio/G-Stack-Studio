Build Pipeline

How Static Multi-Page Generation Works

The software handles everything from HTML markup generation to API payload compression and edge deployment.

1

Template & Palette Selection

Choose from built-in SEO layout templates (such as Luxury Zigzag or Clean Semantic). Pick brand-matched color palettes and set structured schema layouts.

2

Target Provider Configuration

Tick any combination of the 8 supported clouds in the desktop UI. Enter your bucket, site name, or repository. Credentials are authenticated locally in 0.2s.

3

Generate, Deploy & Retrieve URLs

Click Build. The desktop engine compiles all pages, connects links, uploads via official APIs, and returns a verified list of live public URLs for client reporting.
